# Diarista Fácil 🧽

**O "iFood das diaristas": conecta diaristas e clientes de forma simples e segura.**

O cliente escolhe o serviço, a data e a diarista; a diarista recebe e gerencia os serviços; o pagamento é feito no app.

## Status (iPhone, SwiftUI)
Telas existentes: login e cadastro, home do cliente, lista de diaristas, seleção de serviço e horário, calendário, quadro de serviços, próximos serviços, histórico, conclusão do serviço com anexos, marketplace de produtos de limpeza, configurações e aparência. Pagamento via **Apple Pay (PassKit)**. Dados locais com SwiftData.

> Backend real (contas compartilhadas entre cliente e diarista, matching, notificações) e a versão **Android** são **planejados**.

## Rodar
Abra `Diarista facil.xcodeproj` no Xcode e rode no simulador de iPhone.

Plano em **[PLANO.md](PLANO.md)**.
